# Mathematical operator illustrations

The canonical README embeds the technical PNG diagrams in this directory.
`formulas.json` and `render.py` retain the mathematical source and renderer;
`requirements-render.txt` declares separate documentation-only dependencies.
Run the renderer in a dedicated documentation environment when needed.

Internal visual-review packages, execution logs and machine-specific acceptance
reports are excluded from the public source set. The diagrams explain bounded
interfaces and do not establish legal correctness or independent review.
The versioned operator contract is in `../../operators-v1.md`.
